# Contributing to Awesome AI/ML Roadmap

Thank you for helping make this resource better! Contributions of all sizes are welcome — from fixing a broken link to adding an entire new topic's resources.

---

## Ways to Contribute

- **Add a new resource** to an existing topic
- **Fix a broken link** (open an issue or PR)
- **Improve descriptions** or level tags for existing resources
- **Suggest a new topic** that fits within an existing module

---

## Before You Start

Please make sure your resource:

- Is **publicly accessible** (no paywalls without a *(Paid)* label)
- Is **directly relevant** to the topic it's listed under
- Is from a **reputable source** (official docs, well-known YouTube channels, established course platforms, or peer-reviewed articles)
- Has not already been added

---

## Resource Format

Follow this exact format when adding a resource:

```
- [ICON] [Title — Source/Author](url) `Level`
```

For free structured courses, add `*(Free)*`. For paid resources, add `*(Paid)*`:

```
- 🎓 [Kaggle: Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning) `Beginner` *(Free)*
- 💰 [Hands-On Machine Learning — Aurélien Géron](https://www.oreilly.com/...) `Advanced` *(Paid)*
```

### Icons

| Icon | Use for |
|------|---------|
| 📺 | YouTube videos |
| 📄 | Articles and blog posts |
| 📘 | Official documentation |
| 🎓 | Free structured courses |
| 💰 | Paid courses or books |

### Level Tags

| Tag | Meaning |
|-----|---------|
| `Beginner` | No prior knowledge needed |
| `Intermediate` | Requires basic familiarity |
| `Advanced` | Deep knowledge or prior experience required |

Resources within each topic **must be kept in order**: Beginner first, Advanced last.

---

## How to Submit a Pull Request

1. **Fork** this repository
2. **Edit** `RESOURCES.md` — find the correct module and topic section
3. **Add your resource** following the format above
4. **Commit** with a clear message, e.g.:
   ```
   Add PyTorch official beginner tutorial to Module 8 (Deep Learning > PyTorch)
   ```
5. **Open a Pull Request** and briefly describe:
   - What resource you added
   - Why it's a good fit
   - Which topic/module it belongs to

---

## Reporting Broken Links

Open a [GitHub Issue](../../issues) with:
- The broken URL
- The module and topic it appears in
- A replacement URL if you have one

---

## Code of Conduct

Be respectful. This is a community resource for learners. Contributions that add genuine value are always welcome regardless of your background or experience level.

---

Thank you for contributing!
